# Notebook Example

The optional notebook at
`examples/notebooks/hidden_attractors_quickstart.ipynb` demonstrates the
dimension-agnostic trajectory-characterization API. It constructs a small
synthetic trajectory and computes finite-time boundedness, range, variance,
and spectral summaries.

The notebook does not load repository records or start an attractor-localization
workflow. Its output is illustrative and does not certify chaos or hiddenness.
For the complete callable interface and CSV examples, see
[Dynamical Analysis](dynamical_analysis.md).
