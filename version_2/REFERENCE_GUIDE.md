# Reference guide

The maintained public reference is split by purpose:

- [README.md](README.md) introduces installation, the command-line interface,
  and the two independent library scopes.
- [USER_MANUAL.md](USER_MANUAL.md) documents supported workflows and examples.
- [docs/scientific_scope.md](docs/scientific_scope.md) lists the public
  dynamical-system characterization APIs and their evidence boundaries.
- [docs/api_stability.md](docs/api_stability.md) records stable and
  experimental API tiers.

Completed validation records are kept under `validation/`; the frozen
verification snapshot is under `validation/freeze_audit/`. Only supported
software interfaces and completed validation records form this public
reference.
