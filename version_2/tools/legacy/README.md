# Closed Danca Reference Validation

This directory contains one repository-only helper for the partial published
Danca 2017 Chua validation. The article does not disclose the initial
condition of its reported attractor, so the retained code validates only the
published parameters, equilibria, and ABM/full-history method contract.

It does not run trajectories or certify chaos or hiddenness. It is excluded
from the installed library and does not define a public command.
